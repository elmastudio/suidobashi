# Suidobashi

Suidobashi is a minimal, clean Portfolio theme to feature your creative work or projects. Using the Jetpack plugins portfolio custom post type, your online portfolio becomes very flexible. Suidobashi also comes with a default blog layout, so you can include news or a journal on your portfolio website.

By [Elmastudio](https://www.elmastudio.de/en/).

- **Version:** 1.0.11
- **Theme page:** https://www.elmastudio.de/en/themes/suidobashi/
- **Documentation:** [English](https://www.elmastudio.de/en/docs/suidobashi/) / [German](https://www.elmastudio.de/doks/suidobashi/)

## Installation

Download this repository as a ZIP and upload it in **Appearance → Themes → Add New → Upload Theme**, or clone it into your WordPress installation:

```
cd wp-content/themes
git clone https://github.com/elmastudio/suidobashi.git
```

## Updates

Install the Git Updater plugin (https://git-updater.com/) and WordPress will offer new versions of this theme as regular theme updates, straight from GitHub.

## Status

This theme is no longer actively developed. It is published here as-is, for anyone who still runs it or wants to build on it.
